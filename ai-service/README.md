# MoryaBuild AI Service

This FastAPI service provides cost-overrun and schedule-delay risk signals.

## Model status

The service starts safely without model artifacts. In that state, `POST /predict` returns `status: MODEL_NOT_TRAINED` and uses the existing Earned Value Analysis rule-based fallback. That fallback is not a machine-learning prediction.

`src/train.py` can train the two regressors from the reproducible synthetic demonstration dataset generated by `src/generator.py`. The generated data is not production history and must not be used to claim real-world accuracy. Training writes artifacts under `ai-service/models/`; that directory is intentionally absent until training succeeds.

## Run locally

```powershell
cd ai-service
python -m pip install -r requirements.txt
python -m uvicorn src.app:app --reload --port 8000
```

The API is `POST http://localhost:8000/predict`. It accepts the existing project feature payload and returns both cost and schedule risk, explanations, recommendations, and an explicit model status.

To train the demonstration models intentionally:

```powershell
python -m src.train
```

Training metrics describe the synthetic demonstration dataset only. The backend remains responsible for authentication, project authorization, and database access; this service does not connect to MySQL or accept credentials.
